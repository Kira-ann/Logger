# Разработанная библиотека

Библиотека для асинхронного логирования с поддержкой уровней важности (`DEBUG`, `INFO`, `ERROR`) и многопоточное консольное приложение для её тестирования.

---

## Структура проекта

- **`logger_lib/`** — статическая и динамическая библиотека логирования.  
  Содержит:
  - `level.h/cpp` — перечисление уровней важности и функции.
  - `logger.h/cpp` — класс `Logger` с методами записи, фильтрации и смены уровня.
  - `CMakeLists.txt` — сборка библиотеки (статической и динамической).

- **`app/`** — многопоточное приложение для проверки библиотеки.  
  - `app.cpp` — точка входа. Запускает фоновый поток для записи, читает сообщения из консоли, парсит уровень и отправляет в потокобезопасную очередь.

- **`CMakeLists.txt`** — корневой файл сборки проекта.

---

## Сборка

```bash
mkdir build && cd build
cmake ..
make
```

## Запуск

```bash
./app/app <filename> <level>
```

- `<filename>` — имя файла для журнала.
- `<level>` — уровень по умолчанию (`DEBUG`, `INFO` или `ERROR`).



**Пример:**


```bash
./app/app log.txt INFO
```

После запуска вводите сообщения:

```
> Hello, World!
> Error message ERROR
> Debug message DEBUG
> exit
```

- Сообщение `"Hello, World!"` запишется с уровнем `INFO` (по умолчанию).
- `"Error message ERROR"` запишется с уровнем `ERROR`.
- `"Debug message DEBUG"` не запишется, так как `DEBUG` < `INFO`.

---

## Собранные файлы

После сборки в папке `build/` появятся:

- **Библиотеки**:
  - `logger_lib/liblogger_static.a` — статическая версия.
  - `logger_lib/liblogger_shared.so` — динамическая версия.

- **Приложение**:
  - `app/app` — исполняемый файл.

Для запуска используйте `app/app`.

---

## Проверка работы

```bash
cd build
./app/app log.txt INFO
```

Введите несколько сообщений и завершите `exit`.  
Проверьте содержимое файла `log.txt`:

```bash
cat log.txt
```

Пример ожидаемого результата:

```
2026-07-29 19:29:14 INFO Hello, World!
2026-07-29 19:29:20 ERROR Error message
```
